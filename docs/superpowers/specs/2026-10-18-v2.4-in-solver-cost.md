# v2.4 Specification: In-Solver Cost Computation

**Date:** 2026-10-18  
**Status:** Approved  
**Scope:** Refactor optimization examples to use Element + LinearEq constraints for in-solver cost computation, demonstrating and testing v2.3 branch-and-bound pruning.

---

## Executive Summary

v2.3 introduced branch-and-bound optimization (`set_objective()` API) but the examples (TSP, Knapsack) computed cost externally (post-solve), not showcasing the pruning benefit. v2.4 refactors these examples to model cost as constraint variables using existing Element and LinearEq constraints, enabling the solver to prune search based on cost bounds.

**Result:** Examples demonstrate real B&B pruning; `set_objective()` visibly improves search efficiency.

---

## Problem Statement

**Current State (v2.3):**
- TSP and Knapsack examples enumerate solutions via `solve_all()`, then filter and score externally
- `set_objective()` API exists but isn't used in examples because cost isn't modeled as a constraint variable
- Examples work correctly but don't showcase v2.3 optimization capability

**Gap:**
- Users see the API but not the benefit (pruning requires in-solver cost)
- v2.3's B&B pruning is under-tested in realistic example scenarios

**v2.4 Outcome:**
- Cost modeled as constraint variables (using Element + LinearEq)
- Solver prunes search based on cost bounds
- Examples demonstrate real optimization speedup

## Architecture

### Component 1: TSP with In-Solver Cost

**Model:**
```
Variables:
  tour[0..n-1] ∈ {0..n-1}    (next city after city i)
  cost ∈ {0..sum(dist)}       (total tour distance)
  edge_cost[0..n-1] ∈ {0..max_dist}  (distance for each edge)

Constraints:
  AllDiff(tour[0..n-1])       (each city visited once)
  tour[i] ≠ i for all i       (no self-loops)
  For each i: Element(dist_flat, edge_idx(i), edge_cost[i])
    where edge_idx(i) = tour[i-1] * n + tour[i]
    and dist_flat is the distance matrix flattened row-wise
  LinearEq(cost) = sum(edge_cost[0..n-1])

Objective:
  set_objective(cost_cell_idx, minimize=True)
  Solver prunes: skip branches where cost >= best_cost found
```

**Implementation Details:**
- Distance matrix is flattened to 1D array (row-major order)
- n Element constraints (one per edge) map `(prev_city, next_city)` to distance
- One LinearEq constraint sums all edge costs
- Cost cell index is `n + n + 1` (after tour[0..n-1] and edge_cost[0..n-1])

**Example (n=5):**
```python
dist = [
  [0, 2, 3, 4, 5],      # row 0
  [2, 0, 1, 6, 3],      # row 1
  [3, 1, 0, 2, 4],      # row 2
  [4, 6, 2, 0, 1],      # row 3
  [5, 3, 4, 1, 0],      # row 4
]
dist_flat = [0, 2, 3, 4, 5, 2, 0, 1, 6, 3, 3, 1, 0, 2, 4, 4, 6, 2, 0, 1, 5, 3, 4, 1, 0]

s = Store([list(range(5)) for _ in range(5)] +  # tour[0..4]
          [list(range(25)) for _ in range(5)] +  # edge_cost[0..4]
          [list(range(25))])                     # cost

# Constraints...
s.set_objective(n + n, minimize=True)  # cost_cell_idx = 10
```

**Testing:**
- Verify cost cell is fixed to optimal tour cost after solve
- Verify `best_cost()` matches computed tour distance
- Assert cost ≤ known bound (e.g., 12 for benchmark instance)

### Component 2: Knapsack with In-Solver Cost & Weight

**Model:**
```
Variables:
  selected[0..n-1] ∈ {0, 1}  (item included or not)
  value ∈ {0..sum(values)}    (total value)
  weight ∈ {0..sum(weights)}  (total weight)

Constraints:
  LinearEq(value) = sum(selected[i] * items[i].value)
  LinearEq(weight) = sum(selected[i] * items[i].weight)
  weight ≤ capacity           (feasibility constraint)

Objective:
  set_objective(value_cell_idx, minimize=False)
  Solver prunes: skip branches where value <= best_value found
```

**Implementation Details:**
- Two LinearEq constraints: one for value, one for weight
- One linear inequality constraint: weight ≤ capacity
- Value cell index is `n + 1` (after selected[0..n-1])
- Weight cell index is `n + 2`

**Example (n=10, capacity=15):**
```python
items = [(10, 5), (8, 4), (7, 3), (6, 2), (5, 1), (4, 2), (3, 1), (2, 1), (1, 1), (1, 2)]

s = Store([[0, 1] for _ in range(10)] +  # selected[0..9]
          [list(range(50))] +             # value
          [list(range(50))])              # weight

# Constraints...
s.set_objective(n, minimize=False)  # value_cell_idx = 10 (maximize)
```

**Testing:**
- Verify value and weight cells are fixed after solve
- Verify value equals sum(selected[i] * items[i].value)
- Verify weight ≤ capacity
- Assert value ≥ known bound (e.g., 25 for benchmark instance)

## Known Ceilings & Deferred Work

### TSP Distance Matrix Flattening
- **Ceiling:** Linear indexing `row * n + col` for lookups
- **Upgrade path:** v3 multi-dimensional indexing or table constraint
- **Impact:** Works for small n (≤ 10); acceptable for demonstration

### Single Objective
- **Ceiling:** Cannot optimize multiple objectives simultaneously
- **Upgrade path:** v3 multi-objective (Pareto frontier)

### No LP Relaxation
- **Ceiling:** B&B is greedy constraint-based; may explore many branches
- **Upgrade path:** v3 LP relaxation for tighter bounds

## Appendix A: Constraint Reference

### Element Constraint
**Signature:** `("element", (array_indices: List[int], idx_var: int, value_var: int))`

**Semantics:** `value_var == array_indices[idx_var]`

**Example:**
```python
s.post(("element", ([10, 20, 30], 1, 2)))  # cell 2 must equal array_indices[cell 1]
```

### LinearEq Constraint
**Signature:** `("linear_eq", (terms: List[Tuple[int, int]], rhs: int))`

**Semantics:** `sum(cell_i * coef_i for (i, coef_i) in terms) == rhs`

**Example:**
```python
s.post(("linear_eq", ([(0, 2), (1, 3)], 10)))  # 2*cell0 + 3*cell1 == 10
```

## Appendix B: Example Code Outline

### TSP Outline
```python
def run():
    n = 5
    dist = [[0, 2, 3, 4, 5], ...]
    dist_flat = [0, 2, 3, 4, 5, 2, 0, 1, 6, 3, ...]
    
    # Variables
    s = Store([list(range(n)) for _ in range(n)] +      # tour
              [list(range(25)) for _ in range(n)] +      # edge_cost
              [list(range(25))])                         # cost
    
    # Constraints
    s.post(("all_diff", (list(range(n)),)))
    for i in range(n): s.post(("neq_linear", ([(i, 1)], i)))
    for i in range(n):
        s.post(("element", (dist_flat, edge_idx_expr, n + i)))
    s.post(("linear_eq", ([(n + i, 1) for i in range(n)], n + n)))
    
    # Optimization
    s.set_objective(n + n, minimize=True)
    s.solve()
    
    # Verify
    best = s.best_cost()
    assert best <= 12
```

### Knapsack Outline
```python
def run():
    n = 10
    items = [(10, 5), (8, 4), ...]
    capacity = 15
    
    # Variables
    s = Store([[0, 1] for _ in range(n)] +  # selected
              [list(range(50))] +            # value
              [list(range(50))])             # weight
    
    # Constraints
    s.post(("linear_eq", ([(i, items[i][0]) for i in range(n)], n)))
    s.post(("linear_eq", ([(i, items[i][1]) for i in range(n)], n + 1)))
    s.post(("le_linear", ([(i, items[i][1]) for i in range(n)], capacity)))
    
    # Optimization
    s.set_objective(n, minimize=False)
    s.solve()
    
    # Verify
    best = s.best_cost()
    assert best >= 25
```
