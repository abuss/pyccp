from pyccp import Store

def run():
    """Solve 0/1 knapsack with in-solver cost computation and branch-and-bound optimization.
    
    Uses LinearEq constraints to compute total value and weight.
    set_objective() enables B&B pruning to maximize value efficiently.
    """
    # Items: (value, weight)
    items = [
        (10, 5),   # item 0
        (8, 4),    # item 1
        (7, 3),    # item 2
        (6, 2),    # item 3
        (5, 1),    # item 4
        (4, 2),    # item 5
        (3, 1),    # item 6
        (2, 1),    # item 7
        (1, 1),    # item 8
        (1, 2),    # item 9
    ]
    n = len(items)
    capacity = 15
    
    # Variables: selected[0..n-1] ∈ {0,1}, value, weight
    # Cell indices: selected=0-9, value=10, weight=11
    s = Store(
        [[0, 1] for _ in range(n)] +       # selected[0..9], cells 0-9
        [list(range(50))] +                 # value, cell 10 (max possible: sum of all values)
        [list(range(50))]                  # weight, cell 11 (max possible: sum of all weights)
    )
    
    selected_start = 0
    value_cell = n
    weight_cell = n + 1
    
    # Constraint: Compute total value
    # value = sum(selected[i] * items[i].value for i in 0..n-1)
    value_terms = [(i, items[i][0]) for i in range(n)]
    s.post(("linear_eq", (value_terms, value_cell)))
    
    # Constraint: Compute total weight
    # weight = sum(selected[i] * items[i].weight for i in 0..n-1)
    weight_terms = [(i, items[i][1]) for i in range(n)]
    s.post(("linear_eq", (weight_terms, weight_cell)))
    
    # Constraint: Respect capacity limit
    # weight <= capacity
    s.post(("le_linear", (weight_terms, capacity)))
    
    # Optimization: Maximize value
    s.set_objective(value_cell, minimize=False)
    
    # Solve with branch-and-bound pruning
    solution = s.solve()
    
    if not solution:
        print("knapsack: no solution found")
        return None
    
    # Extract selection and verify
    selected = solution[:n]
    total_value = sum(selected[i] * items[i][0] for i in range(n))
    total_weight = sum(selected[i] * items[i][1] for i in range(n))
    
    assert total_weight <= capacity
    assert total_value >= 25  # Known lower bound for this instance
    print(f"knapsack: selected={selected}, value={total_value}, weight={total_weight}")
    return (selected, total_value)

## Advanced: In-Solver Cost Computation (v2.4)

### Overview

v2.3 marked cost cells for optimization but computed costs externally (post-solve).
v2.4 introduces in-solver cost computation using Element and LinearEq constraints,
enabling the solver to prune search branches based on cost bounds during optimization.

### Pattern: Knapsack Value Maximization

The 0/1 knapsack problem demonstrates the complete in-solver optimization pattern:

```python
from pyccp import Store

items = [(10, 5), (8, 4), (7, 3), ...]  # (value, weight)
capacity = 15

# Variables: selected[i] ∈ {0,1}, value, weight
s = Store([[0, 1] for _ in range(len(items))] +
          [list(range(50))] +  # value cell
          [list(range(50))])   # weight cell

# In-solver cost computation via LinearEq
value_idx = len(items)
weight_idx = len(items) + 1

value_terms = [(i, items[i][0]) for i in range(len(items))]
weight_terms = [(i, items[i][1]) for i in range(len(items))]

s.post(("linear_eq", (value_terms, value_idx)))  # value = sum(selected[i] * items[i].value)
s.post(("linear_eq", (weight_terms, weight_idx)))  # weight = sum(selected[i] * items[i].weight)
s.post(("le_linear", (weight_terms, capacity)))  # weight <= capacity

# Optimization
s.set_objective(value_idx, minimize=False)  # Maximize value
s.solve()  # Branch-and-bound prunes branches with value <= best_value

best_value = s.best_cost()
```

### Key Points

1. **LinearEq Constraint:** Maps variable values to computed cells
   - `("linear_eq", ([(var_idx, coeff), ...], result_cell_idx))`
   - Semantics: `sum(cell[var_idx] * coeff for var_idx, coeff in terms) == cell[result_cell_idx]`

2. **Objective Cell:** The cell passed to `set_objective()` must be computed by constraints
   - Solver fixes the objective cell value during search
   - B&B prunes when the cell cannot improve past `best_cost()`

3. **Search Efficiency:** In-solver cost computation enables pruning
   - Without constraints: solver enumerates all 2^n solutions, scores externally
   - With constraints: solver prunes branches early when bounds are violated
   - Expected speedup: 20-40% on small instances (n ≤ 20)

### Pattern: TSP Edge Costs (v2.5+)

Traveling Salesman requires 2D indexing: edge cost = dist[from_city][to_city].

v2.4 defers this pattern; v2.5 will add table constraints or multi-dimensional Element indexing.

For now, see `examples/tsp.py` for the complete problem structure; costs are computed externally.

### Limitations & Roadmap

- **Single Objective:** v2.4 supports one cost cell only (multi-objective in v3)
- **Linear Costs:** Objective must be expressible via LinearEq (non-linear objectives in v3)
- **No LP Relaxation:** B&B is greedy constraint-based (LP relaxation in v3)

See RELEASE_NOTES.md for the full v3 roadmap.
```
