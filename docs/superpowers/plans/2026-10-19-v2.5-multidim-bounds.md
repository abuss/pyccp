**Design (Option A: Encoded Indexing):**

```rust
pub struct Element2D {
    cells: Vec<usize>,         // [all array cell indices, row_var, col_var, result_var]
    array: Vec<usize>,         // linearized 2D array (row-major)
    row_var: usize,
    col_var: usize,
    result_var: usize,
    ncols: usize               // column count for index encoding
}

impl Propagator for Element2D {
    fn propagate(&mut self, store: &mut Store) -> Result<(), Conflict> {
        // When row_var and col_var both fixed:
        //   index = row_val * ncols + col_val
        //   result_var must = array[index]
        //
        // When result_var fixed:
        //   Remove (row, col) pairs where array[row*ncols+col] != result_val
        //
        // Bounds-based pruning when both open:
        //   Tighten result_var bounds from achievable array values
        //   Tighten row/col bounds from achievable indices
    }
}
```

**Propagation Rules:**
1. **Both row_var and col_var fixed:** Compute index, fix result_var
2. **Result_var fixed:** Remove (row, col) pairs that don't map to result_var
3. **Bounds pruning:** When any open, compute achievable bounds for result_var and indices

```rust
pub enum Domain {
    Vec(std::vec::Vec<i64>),  // Existing: enumerated domain
    Bounds(i64, i64),          // New: min and max only
}

impl Domain {
    pub fn is_fixed(&self) -> bool {
        match self {
            Domain::Vec(v) => v.len() == 1,
            Domain::Bounds(min, max) => min == max,  // NEW: O(1) check
        }
    }
    
    pub fn value(&self) -> i64 {
        match self {
            Domain::Vec(v) => v[0],
            Domain::Bounds(min, max) => {
                assert_eq!(min, max, "value() requires fixed domain");
                min
            }
        }
    }
    
    pub fn contains(&self, v: i64) -> bool {
        match self {
            Domain::Vec(vec) => binary_search(vec, v).is_ok(),
            Domain::Bounds(min, max) => v >= *min && v <= *max,  // NEW: O(1)
        }
    }
```

### Task B2: LinearEq Bounds-Only Propagation

**Files:**

**Interfaces:**
- Consumes: LinearEq struct, store (with Domain::Bounds), Bounds reasoner

**Description:**

Update LinearEq to work on bounds when domains are not enumerated. Replace domain iteration (line 208: `for cur in store.domain(c).to_vec()`) with bounds-only logic.

**Propagation Strategy:**

```rust
fn propagate(&mut self, store: &mut Store) -> Result<(), Conflict> {
    // 1. Bounds-based early conflict detection (already exists)
    let (min_sum, max_sum) = self.compute_bounds(store);
    if min_sum > self.rhs || max_sum < self.rhs {
        return Err(Conflict);
    }

    // 2. All-but-one term fixed (already exists)
    let open: Vec<(usize, i64)> = self.terms.iter()
        .filter(|(c, _)| !store.is_fixed(*c)).copied().collect();
    if open.len() > 1 {
        // NEW: For bounds-only cells, just skip tightening (bounds already tight)
        return Ok(());
    }
    
    // 3. All-but-one fixed: solve for the open term
    if open.len() == 1 {
        let (c, k) = open[0];
        let mut sum = self.rhs;
        for (c, k) in &self.terms {
            if store.is_fixed(*c) {
                sum -= k * store.value(*c);
            }
        }
        let v = sum / k;
        
        // NEW: Check if domain is Bounds; if so, tighten bounds instead of iterating
        if store.is_bounds_domain(c) {
            store.tighten_bounds(c, v, v)?;  // Fix to single value via bounds
        } else {
            // OLD: Iterate enumerated domain
            for cur in store.domain(c).to_vec() {
                if cur != v { store.remove(c, cur)?; }
            }
        }
    }
    
    Ok(())
}
```

**Key Changes:**
- When all-but-one fixed: use tighten_bounds(c, v, v) for Bounds, loop for Vec
- When all fixed: verify equation (no change)
- When multiple open: skip (no new pruning for bounds-only)

- [ ] Add helper method store.is_bounds_domain(cell) → bool
- [ ] Update LinearEq::propagate() all-but-one case to check domain type

### Task B4: AllDiff Advanced Bounds Reasoning

**Files:**
- Modify: `rust/src/propagators.rs:92–152` (AllDiff::propagate)

**Interfaces:**
- Consumes: AllDiff struct, store (with Domain::Bounds), all_different constraints
- Produces: Updated propagate() with advanced bounds reasoning for disjoint intervals

**Description:**

AllDiff currently (line 120) calls `collect_all_values()` which enumerates ALL values from ALL domains. For Bounds domains, this creates a union of all (min, max) intervals, which can be huge (m=29 → 536M values).

**Advanced Bounds Reasoning Strategy:**

Instead of enumerating, check if (min, max) intervals are **disjoint**:
- If all intervals disjoint by construction → constraint automatically satisfied (skip propagation)
- If intervals overlap → two cases:
  1. Enough distinct values available → proceed with advanced reasoning
  2. Tight bounds required → emit warning or fail gracefully (defer to search)

**Implementation:**

```rust
fn propagate(&mut self, store: &mut Store) -> Result<(), Conflict> {
    // Collect all (min, max) bounds for each cell
    let bounds: Vec<(i64, i64)> = self.cells.iter()
        .map(|c| store.bounds(*c))
        .collect();
    
    // Check if all intervals are disjoint
    let sorted_bounds = sort_by_min(&bounds);
    let mut prev_max = i64::MIN;
    for (min, max) in sorted_bounds {
        if min <= prev_max {
            // Overlap detected; need full reasoning
            return advanced_all_diff_reasoning(self, store);
        }
        prev_max = max.max(prev_max);
    }
    
    // All disjoint: constraint automatically satisfied
    Ok(())
}

fn advanced_all_diff_reasoning(alldiff: &mut AllDiff, store: &mut Store) -> Result<(), Conflict> {
    // Fall back to existing propagation for enumerated domains
    // For mixed/bounds: use bounds tightening + deferred reasoning
    
    // Enumerate fixed values to block from other domains
    let fixed_values: BTreeSet<i64> = alldiff.cells.iter()
        .filter(|c| store.is_fixed(*c))
        .map(|c| store.value(*c))
        .collect();
    
    // Remove fixed values from other cells' domains
    for c in &alldiff.cells {
        if !store.is_fixed(*c) {
            for v in &fixed_values {
                if store.is_bounds_domain(*c) {
                    // For bounds: check if v is in bounds; if unique match, tighten
                    let (min, max) = store.bounds(*c);
                    if *v >= min && *v <= max && min == max {
                        // Single value matches constraint
                        continue;
                    }
                } else {
                    // For Vec: remove as normal
                    store.remove(*c, *v)?;
                }
            }
        }
    }
    
    Ok(())
}
```

**Step-by-Step (Advanced):**
- [ ] Add bounds-interval disjointness check to AllDiff::propagate()
- [ ] If all disjoint: return Ok() without further propagation (safe, complete)
- [ ] If overlapping: call advanced_all_diff_reasoning()
- [ ] In advanced reasoning: remove fixed values from other domains
- [ ] For Bounds cells: check if fixed value matches; if unique, no conflict
- [ ] Test: AllDiff with mix of Vec and Bounds domains
- [ ] Document limitation: "AllDiff advanced reasoning handles overlapping intervals; defers to search if bounds too tight"

```python
def estimate_domain_size(coeffs):
    """Estimate 2^|coeffs| growth (heuristic)."""
    # For random coeffs, expected subset-sum domain ≈ 0.7 * 2^|coeffs|
    return int(0.7 * (2 ** len(coeffs)))

def make_domain(coeffs, m_items):
    """Create enumerated or bounds domain based on heuristic."""
    estimated_size = estimate_domain_size(coeffs)
    
    # Dynamic threshold: tune based on problem size
    # Small instances (m <= 10): always enumerate
    # Medium (10 < m <= 20): threshold ~10K
    # Large (m > 20): threshold ~1K

        for c in coeffs:

        return ("bounds", min(sums), max(sums))

        for c in coeffs:
```

```python
import time

        try:
            run(f'examples/mknapsack/data/{filename}')
            elapsed = time.time() - t0
            results.append({
                'instance': filename,
                'm_items': m,
                'time_seconds': elapsed,
                'status': 'OK'

            results.append({
                'instance': filename,
                'm_items': m,
                'time_seconds': None,
                'status': f'TIMEOUT/ERROR: {e}'
            })
    
    # Print results
    print("MKP Scaling Benchmark Results:")
    for r in results:
        print(f"  {r['instance']:15} m={r['m_items']:2} {r['time_seconds']:6.2f}s  {r['status']}")
    
    return results

if __name__ == '__main__':
```
